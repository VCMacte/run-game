# Кубок и миры, этап 1 — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ребёнок видит призовой кубок с двенадцатью уровнями, выбирает мир
перед забегом (запертые миры показаны со сноской «ещё N колец») и получает на
сотне колец первый настоящий приз — искры у собранного кольца.

**Architecture:** Уровень и открытые призы НЕ хранятся — их вычисляет чистый
новый модуль `js/awards.js` из копилки `bank`, которая монотонна и отката не
имеет. Реестр миров живёт в `js/theme.js` (`WORLDS`), реестр призов — в
`js/awards.js`; имя каждой вещи лежит ровно в одном из них. В профиль
добавляется одно поле — `world`. Набор открытого фиксируется на старте забега и
едет параметром в отрисовку, которая про хранилище не знает.

**Tech Stack:** Голые ES-модули без сборщика и без зависимостей. Тесты —
обычные скрипты `node` (`node tests-shell.mjs`, `node tests-control.mjs`), без
раннера. Офлайн-кэш и номер версии генерируются `node tools/make-sw.mjs`.

**Spec:** [`../specs/2026-10-16-trophy-and-worlds-design.md`](../specs/2026-10-16-trophy-and-worlds-design.md)

## Global Constraints

- **Шаг лестницы — 100 колец, уровней 12, вершина 1200.** Миры на 300, 600, 900.
- **Ни один приз не меняет приговор:** ни расстановку, ни пороги, ни телеграф,
  ни ступень сложности, ни словарь управления (шаг в сторону и присед).
- **Косметика заменяет, а не добавляет.** Худший кадр сейчас **113 при потолке
  150 и мягком рубеже 120**; добавляющий приз оплачивается ЗАРАНЕЕ ручкой
  `DECOR.gapS`, в том же изменении.
- **Три копии числа худшего кадра** (`CLAUDE.md`, комментарий у `DECOR.gapS`,
  счётчик в группе «бюджет кадра») сверяются ТОЧНЫМ равенством.
- **Новое поле профиля добавляется в ДВА места** — в заготовку нового игрока и
  в `read()` в `js/players.js`: `read()` собирает профиль поимённо, незнакомое
  поле теряется молча.
- **Правка кода и правка документации едут ОДНИМ изменением.** Строка
  «Разбор:» в файле кода и строка «Код:» в теме сверяются тестом в ОБЕ стороны;
  новая тема обязана попасть в индекс `CLAUDE.md`, иначе падает группа
  «документация разбита».
- **Исторические имена не переименовываются:** «звёзды» в коде (`starX`,
  `makeStars`, `s.taken`) — это кольца на экране; ключи хранилища `run-game.*`.
- **Списки офлайн-кэша и номер версии ГЕНЕРИРУЮТСЯ** — после добавления любого
  нового файла запускается `node tools/make-sw.mjs`, руками `sw.js` не правится.
- **Отказ подсистемы молчит и забег не роняет.** Исключение — запись рекорда.
- **Miracast:** различать заливкой и светлотой, не тонкой рамкой и не тоном.
- **Не больше четырёх параллельных процессов.** Здесь это и не нужно: оба
  набора — короткие однопоточные скрипты, запускать по одному.

## Review Focus

Пять входов, которые спек подразумевает, но ни одна задача не обязана была бы
проверить сама. Каждая строка получает тест в задаче-владельце.

1. **Копилка выше вершины** (1200, 5000, 100000): `levelAt` обязан зажаться
   двенадцатью, `nextAt` — вернуть `null`, кубок — залить все полосы, а не
   упасть на тринадцатой. → Задача 1 (математика проверяется тестом; сам
   кубок на экране — только прогоном, в node DOM нет).
2. **Один забег пересекает ДВА уровня сразу** (копилка 90, собрано 220):
   событий `trophy.level` обязано уйти столько, сколько уровней взято, а на
   экране показывается ПОСЛЕДНИЙ взятый — ребёнок читает одну строку. → Задача 6.
3. **Выбранный мир не открыт, неизвестен или мусор** (`p.world = 'ice'` при
   копилке 0, `p.world = 42`, `p.world = 'нет такого'`): забег идёт в `hills`,
   молча, и экран выбора не запирает ребёнка в недоступном мире. → Задача 3.
4. **Новый игрок, копилка 0:** кубок открывается пустым и не падает, `nextAt`
   даёт уровень 1 и остаток 100, строка результата про уровень не появляется
   вовсе. → Задача 1, Задача 4, Задача 6.
5. **Приз открыт, но не реализован** (копилка 300 на этапе 1 — мира ещё нет):
   выбор такого мира показывает `showSoon` с его именем, а не пустой забег и не
   молчание. → Задача 5.

```js
/* ───────────────── кубок ─────────────────

   Уровень НЕ хранится: он вычисляется из копилки. Значит проверять надо ровно
   одно — что вычисление монотонно и на границах не врёт. Список открытого при
   большей копилке обязан ВКЛЮЧАТЬ список при меньшей: копилка растёт и отката
   не имеет, и приз, пропавший от прибавки колец, — худшее, что здесь может
   случиться с ребёнком. */
group('кубок', () => {
  check('двенадцать ступеней', TROPHY.length === TOP_LEVEL, `${TROPHY.length}`);
  check('шаг сотня', STEP_RINGS === 100, `${STEP_RINGS}`);

  // Порог ступени — её номер, умноженный на шаг. Проверяется формулой, а не
  // списком: список был бы второй копией таблицы.
  TROPHY.forEach((row, i) => {
    check(`ступень ${i + 1}: порог ${(i + 1) * STEP_RINGS}`,
      row.at === (i + 1) * STEP_RINGS, `${row.at}`);
    check(`ступень ${i + 1}: есть цвет`, /^#[0-9a-f]{6}$/.test(row.color || ''), row.color);
    check(`ступень ${i + 1}: есть имя`, prizeName(row).length > 0);
  });

  // Миры стоят на каждом третьем уровне, вершина — не мир.
  const миры = TROPHY.filter((r) => r.kind === 'world').map((r) => r.at);
  check('миры на 300, 600, 900', String(миры) === '300,600,900', String(миры));

  // Границы. Именно здесь живут все ошибки на единицу.
  for (const [bank, lv] of [[0, 0], [1, 0], [99, 0], [100, 1], [199, 1], [200, 2],
                            [1199, 11], [1200, 12], [5000, 12], [100000, 12]]) {
    check(`копилка ${bank} → уровень ${lv}`, levelAt(bank) === lv, `${levelAt(bank)}`);
  }
  /* Мусор вместо числа даёт нулевой уровень, а не NaN. Копилка читается из
     localStorage, и один испорченный профиль не вправе уронить кубок. */
  for (const bad of [NaN, Infinity, -5, null, undefined, '300', {}]) {
    check(`мусорная копилка ${String(bad)} → уровень 0`, levelAt(bad) === 0, `${levelAt(bad)}`);
  }

  /* Монотонность открытого — главная проверка этой группы. */
  let прошлый = unlockedAt(0);
  for (let bank = 50; bank <= 1500; bank += 50) {
    const нынешний = unlockedAt(bank);
    for (const [k, v] of Object.entries(прошлый)) {
      if (k === 'worlds') {
        for (const w of v) {
          check(`копилка ${bank}: мир ${w} не отобран`, нынешний.worlds.includes(w));
        }
      } else if (v) {
        check(`копилка ${bank}: приз ${k} не отобран`, нынешний[k] === true);
      }
    }
    прошлый = нынешний;
  }

  check('у нового игрока открыт только первый мир',
    String(worldsAt(0)) === 'hills', String(worldsAt(0)));
  check('и на 900 открыты все четыре', worldsAt(900).length === 4, String(worldsAt(900)));
  check('искры открываются ровно на сотне',
    unlockedAt(99).sparks === false && unlockedAt(100).sparks === true);

  check('на вершине следующего уровня нет', nextAt(1200) === null);
  check('и выше вершины тоже нет', nextAt(9999) === null);
  const n0 = nextAt(0);
  check('у нового игрока следующий — первый уровень',
    n0 && n0.level === 1 && n0.at === 100 && n0.left === 100, JSON.stringify(n0));
  check('остаток считается от копилки', nextAt(150)?.left === 50, `${nextAt(150)?.left}`);

  /* Светлота цветов кубка строго возрастает — кубок читается как
     «наливается» даже когда Miracast съел цветность. Проверяется той же
     функцией, что и палитра коридора, и с зазором: слипшиеся по светлоте
     полосы на телевизоре неразличимы, хотя формально «возрастают». */
  let прошлая = -1;
  for (const row of TROPHY) {
    const l = luminance(row.color);
    check(`${row.id}: светлее предыдущей полосы минимум на 0.04`, l - прошлая >= 0.04,
      `${l.toFixed(4)} после ${прошлая.toFixed(4)}`);
    прошлая = l;
  }
});
```

```js
// Кубок: лестница призов за собранные кольца.
//
// Уровень НЕ хранится — он вычисляется из копилки. Копилка монотонна и отката
// не имеет (см. docs/menu-and-navigation.md), значит множество открытого
// восстановимо из одного числа, и второй копии порогов не заводится. Список
// открытого в профиле был бы ровно той второй копией: поменяли порог — и у
// старых игроков рассогласование, которое видно только на второй сессии.
//
// Здесь нет ни DOM, ни хранилища, ни воркеров — по той же границе, по которой
// js/signals.js проверяется обычным node.
//
// Разбор: docs/trophy-and-worlds.md

import { WORLDS } from './theme.js';

/** Шаг лестницы в кольцах. Решение заказчика, не выведено ни из чего. */
export const STEP_RINGS = 100;

/** Вершина. Лестница конечная намеренно: уровни без призов обесценили бы те,
    за которыми приз есть. */
export const TOP_LEVEL = 12;

/* Таблица. Порядок = номер уровня, порог = номер × шаг, и формула эта
   проверяется тестом — список порогов был бы второй копией шага.

   `kind` отвечает на один вопрос: приз это внешность или мир. Мир
   взаимоисключающий и выбирается, косметика накопительна и действует сама.

   Имя мира здесь НЕ лежит: оно лежит в `WORLDS` в js/theme.js, вместе с его
   зонами. Две копии имени разъехались бы ровно так же, как разъезжаются две
   копии числа. Поэтому у мировых строк имени нет, а спрашивают его через
   `prizeName`.

   Цвета — половина палитры ЭКРАНОВ, не коридора: контракт DECISION/BACKGROUND
   на кубок не распространяется. Но светлота обязана строго возрастать от
   основания к вершине, с зазором 0.04, — это и проверяется. */
export const TROPHY = [
  { at: 100,  kind: 'cosmetic', id: 'sparks',  name: 'Искры',          color: '#1f4d2e' },
  { at: 200,  kind: 'cosmetic', id: 'bloom',   name: 'Цветущая обочина', color: '#2e6b3a' },
  { at: 300,  kind: 'world',    id: 'world-ice',   world: 'ice',       color: '#3f8c46' },
  { at: 400,  kind: 'cosmetic', id: 'fanfare', name: 'Фанфара',        color: '#57a341' },
  { at: 500,  kind: 'cosmetic', id: 'rim',     name: 'Ободок',         color: '#76b53c' },
  { at: 600,  kind: 'world',    id: 'world-deep',  world: 'deep',      color: '#9bc23e' },
  { at: 700,  kind: 'cosmetic', id: 'firefly', name: 'Светлячки',      color: '#c7c93f' },
  { at: 800,  kind: 'cosmetic', id: 'chime',   name: 'Звонкий сбор',   color: '#f2c94c' },
  { at: 900,  kind: 'world',    id: 'world-stars', world: 'stars',     color: '#f0d472' },
  { at: 1000, kind: 'cosmetic', id: 'buddy',   name: 'Спутник',        color: '#f4de96' },
  { at: 1100, kind: 'cosmetic', id: 'trail',   name: 'Шлейф',          color: '#f9e9b8' },
  { at: 1200, kind: 'cosmetic', id: 'gold',    name: 'Золотой кубок',  color: '#fff4d2' },
];

/** Имя приза для экрана. У мира берётся из реестра миров — там оно и живёт. */
export function prizeName(row) {
  if (!row) return '';
  if (row.kind === 'world') return `Мир: ${WORLDS?.[row.world]?.name || row.world}`;
  return row.name || row.id;
}

/** Уровень по копилке: 0…TOP_LEVEL. Мусор даёт 0 — один испорченный профиль не
    вправе уронить кубок. */
export function levelAt(bank) {
  if (typeof bank !== 'number' || !Number.isFinite(bank) || bank <= 0) return 0;
  return Math.min(TOP_LEVEL, Math.floor(bank / STEP_RINGS));
}

/* Набор открытого. Собирается ПЕРЕБОРОМ таблицы, а не списком полей: новая
   строка в TROPHY не должна требовать правки этой функции — иначе появится
   приз, который таблица обещает, а набор не отдаёт. */
export function unlockedAt(bank) {
  const lv = levelAt(bank);
  // Первый мир открыт всегда: в него и уходит забег, когда выбранный недоступен.
  const out = { worlds: ['hills'] };
  for (const row of TROPHY) if (row.kind !== 'world') out[row.id] = false;
  for (let i = 0; i < lv; i++) {
    const row = TROPHY[i];
    if (row.kind === 'world') out.worlds.push(row.world);
    else out[row.id] = true;
  }
  return out;
}

/** Следующий уровень и остаток до него; на вершине — null. */
export function nextAt(bank) {
  const lv = levelAt(bank);
  if (lv >= TOP_LEVEL) return null;
  const row = TROPHY[lv];
  const имею = typeof bank === 'number' && Number.isFinite(bank) && bank > 0
    ? Math.floor(bank) : 0;
  return { level: lv + 1, at: row.at, left: row.at - имею, name: prizeName(row) };
}

/** Доступные миры. Первый — всегда. */
export function worldsAt(bank) {
  return unlockedAt(bank).worlds;
}
```

## Уровень не хранится, а вычисляется

**Открытое — функция копилки, а не состояние.** `levelAt(bank)` в
`js/awards.js` даёт уровень, `unlockedAt(bank)` — набор призов. Копилка
монотонна и отката не имеет, значит множество открытого восстановимо из одного
числа; разбор самой копилки — в
[`menu-and-navigation.md`](menu-and-navigation.md), и здесь он не повторяется.

Список открытого в профиле был бы второй копией порогов — тем самым «самым
частым дефектом проекта». Расходится он молча: поменяли порог, и у старых
профилей приз остался открытым без оснований.

Цена решения названа прямо: **приз нельзя подарить в обход колец.** Если
понадобится — поле `bonus` складывается с копилкой ДО вычисления уровня, и
монотонность не теряется. Отбирать приз нельзя никаким способом, и это не
недоделка: приз, пропавший от прибавки колец, — худшее, что здесь может
случиться с ребёнком, и ровно это проверяет монотонность в группе «кубок».

## Порог считается формулой, а имя живёт в одном месте

**Порог ступени — её номер, умноженный на `STEP_RINGS`,** и тест проверяет
именно формулу. Список порогов рядом с шагом был бы второй копией шага.

**Имя мира лежит в `WORLDS` (`js/theme.js`), а не в таблице призов.** Таблица
знает только `world: 'ice'`; имя спрашивают через `prizeName`. Две копии имени
разъехались бы так же, как две копии числа.

## Цвета кубка проверяются светлотой, а не глазом

Двенадцать полос, светлота строго возрастает от основания к вершине с зазором
0.04. Зазор не украшение: формально возрастающие, но слипшиеся цвета на
телевизоре неразличимы, а Miracast режет цветность сильнее светлоты. Кубок
поэтому читается как «наливается» даже когда цвет пропал.

Цвета живут в половине палитры ЭКРАНОВ, и контракт `DECISION`/`BACKGROUND` на
них не распространяется — разбор этого рубежа в
[`ui-and-layout.md`](ui-and-layout.md).

/* Список миров. Строится по реестру WORLDS, а порог берётся из таблицы
   призов: имя живёт в одном месте, порог — в другом, и копий ни у того, ни у
   другого нет.

   Три состояния у кнопки, и все три видны:
     — открыт и собран: нажимается, выбирает;
     — открыт, но арт не собран: нажимается и честно говорит «скоро»;
     — не открыт: гаснет и показывает, сколько колец осталось. */
function renderWorlds() {
  const bank = players.bank();
  const открыты = worldsAt(bank);
  const выбран = players.world();
  const list = $('worldList');
  list.innerHTML = '';
  for (const w of Object.values(WORLDS)) {
    const порог = TROPHY.find((r) => r.world === w.id)?.at ?? 0;
    const открыт = открыты.includes(w.id);
    const b = document.createElement('button');
    if (открыт) {
      b.innerHTML = `${w.name}${worldReady(w.id) ? '' : '<small>скоро</small>'}`;
      if (w.id === выбран) b.className = 'chosen';
      b.onclick = () => {
        if (!worldReady(w.id)) {
          showSoon(w.name, 'Этот мир ещё рисуется. Пока побегаем в открытых.');
          return;
        }
        players.setWorld(w.id);
        renderWorlds();
        refreshMenuWorld();
      };
    } else {
      const left = порог - Math.max(0, bank);
      b.innerHTML = `${w.name}<small>ещё ${left} ${plural(left, RINGS)}</small>`;
      b.disabled = true;
    }
    list.appendChild(b);
  }
}

**Фильтра в этой цепочке НЕТ — проверено, там стоит просто `].join('')`.**

закрывающую строку сборки на:

```js
    ].filter(Boolean).join('');
```

Это единственное место, где цепочка правится, и пропустить его нельзя: дефект
молчит в node и виден только на экране результата, причём лишь в забеге, где
уровень НЕ взят.

## Три ошибки этого плана, исправленные по итогам ревью

Правки внесены выше, прямо в код задач; названы здесь, потому что следующий
этап копирует этот план и повторил бы их.

**`calc(var(--vh) * 46)` вместо `* 0.46`.** `--vh` — это ЦЕЛАЯ высота окна в
пикселях (`js/app.js` пишет туда `${h}px`), а не её процент. Кубок вышел
36 000 пикселей в высоту, и кнопка «Назад» уехала за экран — ровно тот отказ,
который комментарий строкой выше обещал не допустить.

**`setAttribute('fill', …)` для полос кубка.** Презентационный атрибут SVG
входит в каскад с нулевой специфичностью и проигрывает любому правилу автора,
в том числе правилу запертой полосы. Все двенадцать полос оставались серыми при
любой копилке — то есть функция этапа не работала вовсе, — а ножка с
подставкой, которых код не трогает, рисовались верно: отказ был
самомаскирующимся.

**`color: var(--fg)` на запертой кнопке мира.** На `--dim` это 2.38:1 при
8.56:1 у соседних кнопок того же списка. `--panel` даёт 6.61:1.

**Вывод для будущих этапов: новый CSS обязан получить сторожа в наборе.** Эти
три дефекта прожили 953 + 1691 проверку незамеченными, потому что ни один
набор не смотрел в `css/style.css`. Группа «кубок в стилях» в
`tests-shell.mjs` поставлена именно поэтому.

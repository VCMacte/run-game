# Пятый мир «Пиксельная страна» — план работ

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Цель:** ступень 3000 второго круга кубка открывает пятый мир в стиле
8-битной приставки. Механика прежняя, своя пара препятствий — кубик-слизень и
кирпичная арка.

**Архитектура:** мир — запись в `WORLDS` плюс три зоны в `THEME`, как у
четырёх прежних миров. Все пиксельные фигуры рисует одна функция
`pixelSprite`: один путь и один `fill()` на цвет, поэтому цена фигуры равна
числу её цветов. Анимация идёт кадрами спрайта по фазе времени.

**Стек:** голые ES-модули, Canvas2D, Web Audio. Тесты — `node tests-control.mjs`
и `node tests-shell.mjs`, без раннера.

**Спек:** [`../specs/2026-10-29-pixel-world-design.md`](../specs/2026-10-29-pixel-world-design.md)

## Global Constraints

- Мир `pixel` стоит на **3000** (`js/awards.js`) вместо `title-bolt`. Цвет полосы `#83b2e0` и порог не меняются.
- Мир — ровно **три** зоны: `pixelDay`, `pixelCave`, `pixelCastle`. Каждая есть в `THEME` и задаёт ПОЛНЫЙ набор ключей палитры.
- Цвета решения — `...DECISION` побайтово. `sky` и `floorA` отличаются у всех **пятнадцати** зон.
- Каждый новый цвет отнесён к `DECISION_KEYS` или `BACKGROUND_KEYS`. Фон ниже проёма на `GAP_GUARD`. Зажим неба — `skyClamp(зона)`.
- Худший кадр мира `pixel` — не выше мягкого рубежа **120** (потолок 150). `DECOR.gapS` не трогается.
- Три числа в `docs/frame-budget.md` сверяются с кодом точным равенством. Задача, которая сдвигает худший кадр, правит эти числа в том же коммите.
- Плита препятствия остаётся целиком, цвет `block`. Фигура лежит ПОВЕРХ плиты.
- Спрайт не рисуется, пока клетка меньше `MOTION.pixelMinCell = 2` экранных пикселей.
- Анимация — `Math.floor(elapsed * fps + phase) % n`, без накопленного состояния.
- Узнаваемых персонажей и предметов Nintendo нет (см. анти-цели спека).
- `sw.js` и `js/version.js` переписывает только `node tools/make-sw.mjs`.
- Правка кода и темы — одним коммитом. Шапка нового кода — строка «Разбор:», у темы — строка «Код:».
- Набор печатает число проверок. Каждая задача добавляет хотя бы одну проверку.
- Не больше восьми параллельных процессов.

## Review Focus

1. **Дальнее препятствие в пиксельном мире.** Клетка меньше 2 px — видна голая плита, а не каша квадратиков. → тест в задаче 1 (`pixelSprite` с малой клеткой ничего не рисует).
2. **Слизень в верхнем кадре прыжка выезжает за плиту.** Ожидание — габарит внутри плиты во ВСЕХ кадрах. → тест в задаче 3.
3. **Монетка в узком кадре слишком тонкая.** Ширина ≥ 60% круга во всех кадрах. → тест в задаче 5.
4. **Неизвестная зона или мир.** `worldOf('мусор')` даёт `'hills'`, звук — прежнюю форму. → тесты в задачах 2 и 6.
5. **Пятая карточка мира и 35 медалей не влезают на экран 1280×720.** → проверка кадром в задаче 8.

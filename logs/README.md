# Журналы с телефона

Сюда кладутся файлы `run-game-log-*.json`, выгруженные из приложения:
родительское меню (долгое удержание правого верхнего угла) → «Журнал
событий» → «Выгрузить файлом».

Сами файлы в репозиторий не попадают — в `.gitignore` для них исключение.
Причина не в объёме: репозиторий публичный, а журнал — это запись о том, как
и когда ребёнок играл в своей комнате.

# Замеры с устройства

Источников два:

* `tools/latency.html` — задержка трансляции (этап 0). Пусто до первого
  прогона на телефоне.
* `tools/log-report.mjs` — числа забега из журнала: частота поз, инференс,
  доля колец, паузы и их причины. Ритуал снятия — в скилле
  `.claude/skills/take-measurements/`.

Сюда уезжают **только агрегаты**: герцы, миллисекунды, доли. Сами журналы
остаются вне репозитория (`logs/` в `.gitignore`), и записанные движения
ребёнка — `samples`, `skeleton` — в эту папку не попадают никогда:
репозиторий публичный.
